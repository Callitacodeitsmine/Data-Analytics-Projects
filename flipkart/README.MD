# Flipkart E-Commerce Analytics

## Overview

An exploratory analysis of Flipkart e-commerce data focused on product performance, pricing, ratings, reviews, categories, and customer engagement.

The project combines Python-based analysis, SQL queries, and data visualization to identify patterns and derive business-oriented insights.

## Objectives

- Analyze product and category performance
- Examine pricing, ratings, reviews, and discounts
- Identify high-performing products and categories
- Explore customer engagement patterns
- Generate meaningful analytical insights

## Tech Stack

- **Python** — Pandas, NumPy
- **Visualization** — Matplotlib, Seaborn
- **Database** — MySQL / PostgreSQL
- **Analysis** — Exploratory Data Analysis & SQL
